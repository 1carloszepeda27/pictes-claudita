Cargando Pictes Claudita…

Falta conectar tu base de datos

Este programa guarda todo en Supabase para que tus datos no se pierdan y los veas desde cualquier dispositivo. Antes de usarlo necesitas:

  1. Crear (o reutilizar) un proyecto en supabase.com.
  2. Ejecutar el archivo supabase_schema.sql en el SQL Editor de tu proyecto.
  3. Copiar tu Project URL y tu anon public key (Settings → API).
  4. Abrir este archivo index.html y reemplazar SUPABASE_URL y SUPABASE_ANON_KEY al inicio del <script>.

Revisa LEEME_DESPLIEGUE.md para el paso a paso completo, incluyendo cómo subirlo a Vercel.
